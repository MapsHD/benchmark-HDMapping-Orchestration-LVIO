# Datasets

Place for test datasets and their preprocessed versions. Everything here except this README
and `.gitignore` is git-ignored.

```text
datasets/
├── COCO/                     Newer College Multi-Cam 2021
│   ├── 2021-07-01-10-37-38-quad-easy-004.bag         original bags, names as in ../sequences.conf
│   ├── 2021-07-01-11-31-35_0-quad-medium-001.bag
│   ├── 2021-07-01-11-35-14_0-quad-hard-002.bag
│   ├── 2021-07-01-10-40-50_0-stairs-003.bag
│   ├── cam_calibration/      Kalibr camera-IMU calibration (cam0-1, cam3, cam4); the cam0 values
│   │                         are copied into ../steps/1_prepare_data/coco_calibration.yaml
│   ├── ground_truth/         per-scan 6-DoF ground truth: gt-nc-<sequence>.csv is read by Steps 5 and 6
│   │                         (exact ns stamps; the µs-rounded tum_format/ copy is not used)
│   └── common-ros1/          generated by Step 1: <sequence>.bag, uncompressed ROS 1, read by every algorithm
│                             (an older common/ folder holds unusable LZ4 bags: ../clean.sh removes it)
└── BUNKER/                   Bunker DVI dataset, sequence reg-1 (the LIO benchmark's dataset)
    ├── reg-1.bag             original bag (Livox Mid-360, Alphasense Core, D455F, Azure Kinect), 48 GB
    ├── HDMappingGroundTruth/ ground truth (HDMapping session); lio_result_0/lio_result_0_trajectory_tum.txt
    │                         is read by Steps 5 and 6
    ├── TLS-FARO-Focus/       FARO TLS reference map (map_gt_0.01.laz / .pcd), same frame as the ground truth
    └── common-ros1/          generated by Step 1: reg-1.bag (~5 GB)
```

BUNKER is a copy of `~/hdmapping-benchmark/data/{reg-1.bag,HDMappingGroundTruth,TLS-FARO-Focus}` (LIO benchmark);
the dataset's own download link and calibration files are no longer online. Its calibration is in
`../steps/1_prepare_data/bunker_calibration.yaml`.

`../validate.sh` checks that the bags and ground truth of every sequence in `../sequences.conf` are here.

Source: [Newer College Dataset, Multi-Cam](https://ori-drs.github.io/newer-college-dataset/multi-cam/)
(Ouster OS0-128 + Alphasense Core). Mind the dataset's licence when sharing data or derived bags.
