# Datasets

Place for test datasets and their preprocessed versions. Everything here except this README
and `.gitignore` is git-ignored.

```text
datasets/
├── COCO/                     Newer College Multi-Cam 2021: the benchmark dataset
│   ├── 2021-07-01-10-37-38-quad-easy-004.bag         original bags, names as in ../sequences.conf
│   ├── 2021-07-01-11-31-35_0-quad-medium-001.bag
│   ├── 2021-07-01-11-35-14_0-quad-hard-002.bag
│   ├── 2021-07-01-10-40-50_0-stairs-003.bag
│   ├── cam_calibration/      Kalibr camera-IMU calibration (cam0-1, cam3, cam4); the cam0 values
│   │                         are copied into ../prepare_data_step1/coco_calibration.yaml
│   ├── ground_truth/         per-scan 6-DoF ground truth (csv + tum_format/); not used yet
│   └── common-ros1/          generated by Step 1: <sequence>.bag, uncompressed ROS 1, read by every algorithm
│                             (an older common/ folder holds unusable LZ4 bags: delete it)
└── LVI/                      LVI-SAM dataset (garden, handheld, jackal): not used by the pipeline
                              (no ground truth; COIN-LIO cannot run on its VLP-16)
```

Source: [Newer College Dataset, Multi-Cam](https://ori-drs.github.io/newer-college-dataset/multi-cam/)
(Ouster OS0-128 + Alphasense Core). Mind the dataset's licence when sharing data or derived bags.
